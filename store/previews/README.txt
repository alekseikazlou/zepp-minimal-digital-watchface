Minimal Digital — previews for Zepp Console

Upload files from png/: 34 PNG images, each 360×360 and under 1 MB.
These are Normal-mode previews. AOD is not included. The round screen
has transparent corners.

manifest.json records the language, translation, font, Penpot copy ID,
file size, and SHA-256 checksum.

The PNGs were exported directly from Penpot at a scale of 0.75, without
rendering the text locally. The original Penpot screen is unchanged.
Language copies are arranged in a separate group on the right side of
page 05 · Screens and named:
Store / Minimal Digital / Normal / <locale> · 480.

Weekday names come from watchface/shared/weekdays.js. For the date
25.09.2026, Friday (index 4) replaces the original WEDNESDAY label.
The date format and numeric values match the original design.
The weekday field matches the project configuration: x=110, y=330,
width 260, height 32, font size 26, centered alignment.

The original Inter font is preserved for languages that use Inter in the
watchface. For Chinese, Japanese, Korean, Thai, Arabic, Hebrew, and Hindi,
the copies use Noto fonts for the corresponding scripts. On the watch,
these languages use the Zepp system font; its exact visual match with
Noto has not been verified. These images are design previews, not
screenshots from the watch.

Language codes follow the Zepp language table:
https://docs.zepp.com/docs/reference/related-resources/language-list/
iw-IL is Zepp's code for Hebrew; zh-CN/zh-TW and pt-PT/pt-BR are kept
separate.
